
# 🏋️‍♂️ The Gym Aesthetic Trap

## 📘 Project Overview

This project explores how modern fitness culture is shifting from health-driven goals to aesthetic obsession — backed by data, trends, influencer outcomes, and real-world conversations.

It combines:
- 📈 Economic Analysis (Gym CPI vs. Median Income)
- 🔍 Google Trends (Aesthetics vs. Health, Steroids, SARMs)
- 💀 Influencer Mortality Data (PED-related deaths)
- 💬 Reddit NLP (Word frequency, Sentiment, Topic Modeling)

---

## 🔧 Tech Stack & Libraries

- Python (Jupyter Notebook)
- pandas, matplotlib, seaborn
- pytrends, spacy, nltk, sklearn
- LDA (Topic Modeling via Scikit-learn)
- VADER Sentiment Analyzer (NLTK)

---

## 📊 Key Visual Insights

- **Gym memberships** are rising faster than income — fitness is a luxury.
- **Google Trends** show rising interest in “six pack”, “trenbolone”, and SARMs vs health-oriented searches like “VO2 max”.
- **Influencer mortality** exposes the toll of PED culture — many passed under 40, often from cardiac failure.
- **Reddit NLP** reveals anxiety, steroids, aesthetics, and fat loss dominate online fitness conversations.
