# Gym Aesthetic Trap: The Cost of Looking Fit

## 📖 Overview
This project explores how modern fitness culture has shifted toward aesthetics over health. Using data from gym prices, supplement trends, influencer marketing, and performance-enhancing drugs (PEDs), we investigate:

- Gym inflation and rising membership costs
- The evolving definition of a “fit physique”
- The rise of “fake natty” accusations and PED usage
- Early deaths among fitness influencers
- Health vs. aesthetic trade-offs in modern gym culture

## 🎯 Goals
- Analyze pricing trends in the fitness industry
- Visualize the shift in public sentiment using social media data
- Identify regional gym cost disparities
- Build predictive models for gym price forecasting
- Assess correlations between social pressures and risky fitness behaviors

## 🧰 Tech Stack
- **Python** (pandas, matplotlib, seaborn, scikit-learn)
- **Jupyter Notebooks**
- **VS Code**
- **GitHub**
